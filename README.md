# Phishing Awareness Training

An interactive, self-paced training module that teaches how to recognize and respond to phishing attacks. It runs entirely in the browser as a single HTML page, with no installation, server, or internet connection required.

Built as **Task 2** of the CodeAlpha Cyber Security Internship.

**Live demo:** https://hariharasudhan-nl.github.io/CodeAlpha_-PhishingAwarenessTraining-/

## What You Will Learn

| # | Section | Description |
|---|---|---|
| 1 | Find the red flags | Click through a fake PayPal email and uncover 5 warning signs: lookalike sender, urgency, generic greeting, typos, and a suspicious link. |
| 2 | Recognize fake websites | Real vs. fake URL examples, domain reading tricks, and why the HTTPS padlock does not prove a site is safe. |
| 3 | Social engineering tactics | Urgency, authority, fear, greed, curiosity, and familiarity, plus spear phishing, smishing, vishing, and business email compromise. |
| 4 | Real-world examples | Fake vendor invoices (2013 to 2015), the 2016 Podesta email, the 2017 Google Docs worm, and the 2020 Twitter hack. |
| 5 | Best practices | A 10-point checklist covering MFA, password managers, verification habits, and reporting. |
| 6 | Types of phishing | Email, spear phishing, whaling, BEC, clone phishing, smishing, vishing, quishing, and pharming. |
| 7 | If you are phished | A 6-step response plan, including reporting resources for India. |
| 8 | Key terms | A glossary of common phishing and security terms. |
| 9 | Knowledge check | A 10-question quiz with instant feedback and an 80% pass mark. |

## Features

- Interactive email analysis with clickable red flags
- 10-question quiz with explanations and a scored result
- Dark and light themes, with the choice remembered between visits
- Sticky section navigation and a reading progress bar
- Responsive layout that works on desktop and mobile
- Keyboard-friendly, with visible focus and reduced-motion support
- Single file with no dependencies

## How to Run

**Online:** open the live demo link above.

**Locally:**
```bash

cd CodeAlpha_-PhishingAwarenessTraining-
```
Then open `index.html` in any web browser by double-clicking it.

## Key Takeaways

- Slow down when a message creates urgency or fear.
- Check the sender's real address and the link's real domain before clicking.
- Never share passwords or OTPs by email, SMS, or phone.
- Enable multi-factor authentication on every account that supports it.
- Report suspicious messages, and report mistakes quickly.
